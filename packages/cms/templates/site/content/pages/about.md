This is a page. Pages live in `content/pages/` and, unless the front matter
says otherwise, are served at `/{slug}/`.

The link that brought you here is in the menu because the site says so, not
because this file does. Settings > Reading has a Menu box holding one
`Label | URL` per line, and `About | /about/` is the first of the two lines a
new site starts with. Delete that line and the page is still here at `/about/`;
it is just no longer linked. The box writes `menus.primary` in
`content/_data/site.json`, so editing the file does the same thing.

Edit this file and save it. The change is live before you can switch back to
the browser: the CMS watches `content/` and re-indexes a file the moment it
changes.
