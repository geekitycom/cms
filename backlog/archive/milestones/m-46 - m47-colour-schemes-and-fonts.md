## Description

A site owner can change the look of the default theme without writing a theme: choose one of a fixed set of colour schemes, each tested to 7:1 for text and 3:1 for relied-on borders in light and dark; choose whether it follows the system, or is always light or always dark; and choose a Google Font for headings and one for body text, which the CMS downloads and hosts itself so readers never contact Google. See decision-61.
