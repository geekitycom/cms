## Description

The post and page editor keeps unsaved work. It autosaves the form to a per-user copy under data/autosave, falls back to the browser's localStorage while the server cannot be reached, and offers the copy back when the editor opens or from an Unsaved list. The real document is never written by autosave. A distraction-free mode shows only the title and body, fullscreen where the browser allows, with autosave and a word count. See decision-62.
