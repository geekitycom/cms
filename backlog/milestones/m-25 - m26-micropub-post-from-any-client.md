## Description

Geekity gains a Micropub endpoint (https://www.w3.org/TR/micropub/) and a media endpoint, so a user signed in through M25 IndieAuth can publish, edit and delete posts from clients such as Quill, Indigenous and iA Writer. A Micropub post is an ordinary Markdown file written through the same save path as the admin editor, so it federates, sends webmentions and appears in feeds exactly as an editor post does.
