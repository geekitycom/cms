## Description

Move a WordPress site onto Geekity with nothing lost: every URL still answers, every feed guid and ActivityPub object id stays the same, and the content becomes Markdown files in git. andrewshell.org is the first site through (plan in ~/code/geekity/asdo_geekity/_local/PLAN.md). Its WordPress holds 160 posts, 16 pages, 25 attachments, 69 fediverse and webmention reactions, Jetpack Markdown, and posts carried over from an earlier Eleventy site. The tasks cover what that migration showed core lacks.
