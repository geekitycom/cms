A [now page](https://nownownow.com/about): what has the attention, as of the
date above.

- **Milestone zero.** The package boundary — `createCms`, the config schema,
  the `geekity` bin — and the public site it serves.
- **Next.** Admin authentication, then the editor. Until those land, editing a
  post means editing a file, which is not the worst fallback a CMS has ever
  had.
- **Not yet.** Federation. The content model already carries the fields it will
  need, and nothing federates until there is an account to federate as.

The `updated` field in this file's front matter is what dates this page. It is
a modelled key, so it survives an edit through the admin unchanged.
